# 公開前の法的チェックリスト（重要）

このリポジトリを GitHub で公開する前に、以下を必ず確認してください。
**法的助言ではありません。必要なら弁護士に相談してください。**

## 1. Discord のソフトウェア（著作権）

- 本プロジェクトは **Discord のコードを一切含みません**。
  Electron アプリを再配布しているのではなく、WebView2 で `discord.com` を表示しているだけです。
- したがって「Discord 本体を改造して再配布する」ような著作権侵害（複製権・翻案権）には該当しません。
- ただし Discord の **利用規約（ToS）** は非公式クライアントを禁止しています。
  利用者が BAN される可能性、配布者が規約違反を問われる可能性はゼロではありません。

## 2. Discord のロゴ・名称（商標）

- `discord` のロゴは **Discord Inc. の商標**です。アプリアイコンにそのまま使うと、
  公式製品との混同を招き、**商標権侵害**とみなされる可能性があります。
- 公開する場合は、以下のいずれかを推奨します。
  1. アイコンをオリジナルデザインに差し替える（推奨）
  2. 名称を「Discord」を含まないものにする（例: `fastcord`）
  3. README に「Discord Inc. とは無関係の非公式プロジェクト」と明記する
- ロゴ画像をリポジトリに含めると、GitHub の DMCA / 商標申立てで削除される可能性があります。

## 3. 依存ライブラリのライセンス

- Tauri / wry / tao: MIT / Apache-2.0
- webview2-com / windows-rs: MIT
- 本プロジェクトのコード: MIT（`LICENSE`）

いずれも再配布可能です。`cargo deny` や `cargo license` で確認できます。

## 4. 公開時の推奨

- リポジトリ名・アプリ名から `Discord` を外す、または「非公式」を明記
- アイコンをオリジナルに差し替える
- README 冒頭に免責事項を書く
- Releases にはビルド済みインストーラとソース zip を置く
- ライセンスファイルとサードパーティ通知を含める
