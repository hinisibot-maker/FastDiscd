FastDiscd 設定

設定は即時反映され、自動的に保存されます。
ページ読み込み時にキャッシュを削除
ログイン画面→アプリなど、ページ遷移時に HTTP キャッシュを破棄します
チャンネル切替時に前ページのキャッシュを削除
チャンネルを切り替えたとき、以前のページの画像・GIF キャッシュを破棄します
最小化時にメモリを解放
最小化中は WebView2 を省メモリ状態にします（通知は止まりません）
非フォーカス時にメモリ目標を Low にする
他のウィンドウを操作している間、WebView2 に省メモリ動作を指示します
プッシュトゥトーク（グローバル）
Discord の PTT キーと同じキーを設定してください。別ウィンドウを見ていても反応します
Windows 起動時に自動で開く
HKCU の Run に登録します（管理者権限不要）
起動時は最小化して開始
次回起動から反映されます
最小化時にタスクトレイへ格納
タスクトレイのアイコンを左クリックで戻ります
ハードウェアアクセラレーション（GPU）
オフにすると GPU を使わずに描画します（再起動後に反映）
拡大率
Discord の設定に拡大率が表示されない環境向けの代替設定です
